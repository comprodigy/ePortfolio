CompuStocker

CS 360 Mobile Architecture and Programming. Android inventory app for computer parts. Enhanced for software design and engineering.

What it was

Login and register, a grid of parts, add and delete, optional SMS permission. SQLite on the device. Activities talked to the database directly. Passwords were stored and compared in plaintext. Minimum quantity was set in Java and not stored.

What changed

  • ViewModel and repository. The Activity binds the UI.
  • Salt and SHA-256 hash. Lookup by username, then verify the hash.
  • Session with a 30-minute timeout. Inventory redirects if the session is empty.
  • min_quantity column written on insert and read on load.

Narrative

I picked this artifact because it was the first full project in the degree that I enjoyed, and I already had mobile experience. The enhancement shows I can take a working class app and fix the design the way a team would, not add another screen. The hard part was moving work out of the Activity so the RecyclerView still updated. Password hashing was new to me on Android. Outcomes 2, 4, and 5.
